        02 / Where your data goes
        
        
        Your files are yours. That’s the point.
        
      
        
      
        Not every tool can run without a server, so we won’t pretend they all do. Here is exactly what each one does with what you give it.
        
    
        

    
          
      
        1. 
        
          
          A
          
          Processed in your browser
          
          
          JSON Toolkit · NRIC & FIN · PDF Toolkit · Image Toolkit
          
          
          The code comes to your file, not the other way round. Formatting, page edits, compression and even the background-removal AI run on your own device. There is no upload step to switch off.
          
        
          
        
          
          
          Your devicefile → tool → resultall in the tab
          
          
          nothing sent
          
          
          Our servernever sees it
          
        
          
      
          2. 
      
        2. 
        
          
          B
          
          Stored on our server, under your rules
          
          
          Secure File Sharing
          
          
          A file has to live somewhere for someone else to download it. Direct access to stored files is blocked; each one is served only through its link — which stops working at the expiry date or download limit you set. A link password is stored only as a bcrypt hash. Files are not end-to-end encrypted, so don’t send what needs that.

        3. 
        
          
          C
          
          Encrypted, read once, then gone
          
          
          Self-destructing Secrets
          
          
          Your secret is stored as AES-256-GCM ciphertext. Each view is counted on the server, and the view that reaches the limit deletes the record in the same step. After that, the link has nothing left to show.

        4. 
        
          
          D
          
          Encrypted before it leaves you
          
          
          Vault · account required
          
          
          Your master password is turned into a key with PBKDF2 on your device, and the vault is encrypted with AES-256-GCM before it is saved. We store ciphertext we cannot decrypt — which also means we cannot recover a forgotten master password.

          Read by AI, paid for by credit
          
          
          AI GST Notice Reply Generator · sign-in required
          
          
          To draft a reply, the notice has to be read — so the PDF you upload is sent to our backend and an AI model. The summary is free; a full drafted reply costs one credit, and new accounts start with five. A qualified professional should review every draft.

        03 / How we built them
        
        
        Not a collection of demos. A demonstration of how we build.
        
        
        Each tool started as a problem someone actually had. We built it the way we build for clients — then left it running, in public, where anyone can push on it.
        
      
        
      
      
    
        
    
          
      
        1. 01
          We build real software
          Every tool on this page is in production, on its own domain, used by people we’ve never met. Nothing here is a mock-up.
          2. 
      
        2. 02
          We solve practical problems
          Sending a file without an account. Answering a tax notice before the deadline. Getting a PDF under an upload limit. Small problems, solved properly.
          3. 
      
        3. 03
          We care about speed and use
          Heavy libraries load only when you open the tool that needs them. Errors tell you the line and the fix. Buttons do what they say.
          4. 
      
        4. 04
          We put privacy first
          If a job can run on your device, it does. If it can’t, we say so — and say exactly what happens to your data on the way.
          5. 
      
        5. 05
          We write it ourselves
          No page builders and no templates. The same hands that built these will build yours, around your problem, not a theme’s idea of it.
